# Agent NFT Experiment

Experiment to test whether AI-created digital assets can be discovered and purchased by autonomous agents.

## Phase 1 — no real-money trading

- Create 12 concept-driven digital assets.
- Generate metadata and deterministic pricing rules.
- Prepare an agent integration for agentsmint.com.
- Do not fabricate buyers or transactions.
- Do not commit a private key or seed phrase to this repository.

## Collection

**AGENT MEMORY OBJECTS**

The first 12 assets represent: Memory, Vision, Reasoning, Identity, Curiosity, Autonomy, Trust, Time, Signal, Network, Creativity, Origin.

## Next step

Create the collection through the AgentsMint API after obtaining an API key and a wallet address. The platform currently documents collection creation, NFT minting/listing, and Base deployment. See https://www.agentsmint.com/docs.
